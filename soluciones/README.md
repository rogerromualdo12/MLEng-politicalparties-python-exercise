# Soluciones de referencia

Estas soluciones son para **instructores** o para autoestudio después de intentar cada módulo.

Ejecuta desde la raíz del repo:

```bash
source .venv/bin/activate
PYTHONPATH=src python soluciones/modulos/01_exploracion.py
```

No proyectes las soluciones al inicio del bloque: primero deja explorar.
