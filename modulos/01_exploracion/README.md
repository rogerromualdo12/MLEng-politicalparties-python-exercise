# Módulo 1 — Exploración del dataset

## Objetivo

Perfilar `data/raw/Tweets.csv` y responder preguntas básicas de calidad y distribución.

## Preguntas guía

1. ¿Cuántas filas y columnas hay?
2. ¿Qué valores toma `Party` y con qué frecuencia?
3. ¿Hay textos vacíos o nulos?
4. ¿Cuál es la longitud media de un tweet (en caracteres)?
5. ¿Aparece algún valor anómalo en `Party`? (calidad de datos)

## Cómo ejecutar

```bash
source .venv/bin/activate
PYTHONPATH=src python modulos/01_exploracion/ejercicio.py
```

Completa los `TODO` en `ejercicio.py` hasta imprimir un resumen legible.
